# 快速开始

欢迎使用 AutocodeLLM！本指南将帮助您快速上手。

## 安装

```bash
git clone https://github.com/your-org/autocodellm.git
cd autocodellm
bun install
```

## 配置环境变量

复制 `.env.example` 为 `.env`：

```bash
cp .env.example .env
```

## 启动开发服务器

```bash
bun run dev
```

访问 `http://localhost:3000` 即可开始使用。
