# 模型配置

AutocodeLLM 支持多种 AI 模型提供商。

## 支持的提供商

- **OpenAI**: GPT-4、GPT-3.5-Turbo 等
- **Anthropic**: Claude 系列
- **Google**: Gemini 系列
- **DeepSeek**: DeepSeek-Coder 等

## 配置步骤

1. 进入「模型管理」页面
2. 点击「添加提供商」
3. 填写 API Key 和配置信息
4. 保存并测试连接

## 注意事项

- 请妥善保管您的 API Key
- 建议使用环境变量管理敏感配置
- 测试连接成功后再开始使用
